# hello-world-devops-pipeline
A simple Hello World app containerized with Docker and automated using GitHub Actions CI/CD

This repository demonstrates a simple **Flask "Hello World" web application** that is containerized using **Docker** and automated through a **CI/CD pipeline with GitHub Actions**.  
It also includes unit testing with **pytest** and integration with **DockerHub** for image distribution.  
The goal of this project is to showcase **end-to-end DevOps practices** — from source control to deployment and monitoring.

---

## 🎯 Features

- ✅ Simple Flask web application (`Hello World!`)  
- ✅ Containerized with Docker  
- ✅ Unit testing with pytest  
- ✅ Pushes Docker images to DockerHub
- ✅ Automated CI/CD pipeline using GitHub Actions
